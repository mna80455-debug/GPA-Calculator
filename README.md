# GradeIQ — المستشار الأكاديمي الذكي 🎓

![GradeIQ Banner](gradeiq_banner.png)

**GradeIQ** هو تطبيق ويب متطور مصمم لمساعدة الطلاب على إدارة مسيرتهم الأكاديمية بذكاء. يجمع التطبيق بين التصميم العصري والأدوات التحليلية القوية، بالإضافة إلى مستشار أكاديمي مدعوم بالذكاء الاصطناعي.

**GradeIQ** is a modern, intelligent web application designed to help students manage their academic journey. It combines sleek design with powerful analytical tools and a built-in AI Academic Advisor.

---

## 🚀 المميزات الرئيسية | Key Features

### 1. 📊 لوحة تحكم ذكية | Smart Dashboard
- عرض فوري للمعدل التراكمي (GPA) والساعات المكتسبة.
- نظام "الحالة الأكاديمية" لتنبيهك بوضعك الحالي.
- رسوم بيانية تفاعلية لتوزيع الدرجات.

### 2. 🤖 المستشار الأكاديمي (AI Advisor)
- مدعوم بنموذج **Llama 3.3 70B**.
- يقدم نصائح مخصصة لتحسين معدلك بناءً على بياناتك الفعلية.
- يجيب على استفساراتك حول الخطط الدراسية.

### 3. 🎯 مخطط المعدل | GPA Planner
- حدد المعدل الذي تطمح للوصول إليه.
- يخبرك التطبيق بالضبط بالدرجات المطلوبة في الفصول القادمة لتحقيق هدفك.

### 4. 🧪 محاكي السيناريوهات | What-If Simulator
- جرب تأثير درجات افتراضية على معدلك دون التأثير على بياناتك الحقيقية.
- يساعدك على اتخاذ قرارات مدروسة حول اختيار المواد.

### 5. 🏆 نظام الإنجازات | Achievements System
- تحويل الدراسة إلى تجربة ممتعة من خلال فتح الأوسمة عند تحقيق أهداف أكاديمية معينة.

### 6. 📄 التقارير والتصدير | Export & Reports
- تصدير بياناتك بتنسيق **PDF** أو **Excel/CSV**.
- دعم النسخ الاحتياطي (Import/Export JSON).

---

## 🛠 التكنولوجيا المستخدمة | Tech Stack

- **Frontend**: HTML5, Vanilla CSS, JavaScript.
- **AI Engine**: Groq Cloud (Llama 3.3 70B).
- **Backend**: Firebase Auth & Firestore.
- **Visualization**: Chart.js.
- **Icons**: Lucide Icons.

---

## 📥 التشغيل المحلي | Local Setup

1. قم بعمل `git clone` للمستودع.
2. افتح ملف `index.html` في متصفحك (أو استخدم Live Server).
3. تأكد من إعداد مفاتيح Firebase و Groq في ملف `js/config.js`.
